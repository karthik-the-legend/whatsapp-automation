# Main Branch — Senior Fees

- Monthly fee: ₹2,000
- One free demo/trial session provided initially

If the student joins after the demo:

- Registration: ₹1,500
- Monthly fee: ₹2,000
- **First month training/admission total (excluding uniform): ₹3,500**
- Senior uniform: **₹2,000, charged separately**
- First month total **including** uniform: ₹5,500

Always state the ₹3,500 training/admission total and the ₹2,000 uniform
as two distinct line items - never merge or hide the uniform charge.

From the second month: ₹2,000/month.
